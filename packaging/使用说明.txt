========================================================================
                        社区签到助手  使用说明
                              版本 1.3.9
========================================================================

一、这是什么
------------------------------------------------------------------------
一款在 Windows 电脑上运行的「每日签到任务助手」，目前支持：

    · 米游社（原神 / 崩坏：星穹铁道 / 绝区零 / 崩坏3 / 未定事件簿 / 崩坏学园2）
    · 库街区（鸣潮 / 战双帕弥什）
    · Trae（PC 端 IDE，每日签到领积分，无需模拟器）
    · Qoder（PC 端 AI 编程 IDE，每日领 100 Credits）
    · WorkBuddy（腾讯 AI 办公工作台，每日签到领积分）

主要功能：游戏每日签到、社区打卡、浏览 / 点赞 / 分享任务、任务进度与货币查询、
自动领取奖励、执行明细记录。

所有操作都在你自己的电脑上完成，账号凭证只保存在本机，不会上传到任何服务器。


二、使用前需要准备
------------------------------------------------------------------------
1. Windows 10 / 11（64 位）

2. 一个安卓模拟器（MuMu 模拟器 12、雷电模拟器 9 等都可以），并已开启 ADB 调试。
   · MuMu：模拟器设置 → 其他 → 打开「ADB 调试」，记下端口（默认 16384）
   · 雷电：模拟器设置 → 其他设置 → 打开「ADB 调试」，默认端口 5555

3. 在模拟器里安装并「手动登录」好目标 App：
   · 米游社  包名 com.mihoyo.hyperion
   · 库街区  包名 com.kurogame.kjq
   必须先在 App 里登录一次，程序才读得到登录状态。

4. 本程序已自带 adb，不需要另外安装 Android SDK。


三、第一次使用（4 步）
------------------------------------------------------------------------
第 1 步   启动模拟器，打开并登录米游社 / 库街区，停留在 App 首页。

第 2 步   双击桌面上的「社区签到助手」图标启动程序。

第 3 步   左侧点「账号」→ 右上角「登录账号」→ 选「米游社 / 库街区」→
          「自动获取」→「立即获取登录凭证」：
             库街区 约 5 秒
             米游社 10～40 秒（需要扫描 App 运行内存找登录态）
          获取后点「保存账号」，账号会出现在表格里，状态显示为正常。

第 4 步   左侧点「任务」→ 勾选要做的任务 → 点「开始执行」。
          下方日志会实时打印每一步的结果。

之后每天只需要：模拟器开着 → 打开程序 → 点「一键执行」。


四、界面说明
------------------------------------------------------------------------
总览      当前货币余额、今日已得、每日任务进度、绑定角色。
          右上角「刷新数据」拉取最新进度，「一键执行」直接跑完所有任务。
          「今日已得」是今天真正到账的数量，执行完任务后会自动更新。
账号      多账号管理。同一个平台可以登录多个账号，互相独立、各自签到。
          按钮：登录账号（自动获取 / 手动添加）/ 删除。
          双击表格任意一行，即可把这个账号切换为「当前账号」（当前账号前面有 ●）；
          也可以在「总览」「任务」页右上角的下拉里切换。
任务      顶部「平台账号」下拉可以切换当前要操作的账号，也可以选
          「全部平台（依次执行）」，一次性把所有账号的日常按顺序跑完。
          勾选要执行的任务后点「开始执行」，按钮会立刻变成「停止」，
          下方日志实时打印每一步结果，成功的那一行末尾会写明这一步到账
          多少币（例如 +30 库洛币）。执行中点「停止」，会在当前这一步跑完
          后收手，不会把已完成的记录丢掉；跑完按钮自动变回「开始执行」。
          勾选状态会记住，下次打开还是上次那样。

          定时执行（任务页顶部）：
              勾选「定时自动执行」，选「每天 / 仅工作日」、时间（直接
              键入，如 08:30、21:05），以及要跑的范围（全部平台或某个
              账号），设置立即生效，不用再点保存。
              到点后自动开始，日志里会出现一行「⏰ 定时任务触发」。
              · 程序要开着才会触发，建议同时打开「设置 → 开机自启」；
              · 正在执行别的任务时，这一次会自动跳过；
              · 勾选时今天的时刻已过 → 立即补跑一次（错过的任务尽快
                执行，与 Windows 任务计划的行为一致）；当天已经跑过
                再改时间，下一次从明天算，同一天只跑一次；
              · 程序没开错过了时刻，下次启动也会补跑一次；
              · 重启程序不会重复跑（当天跑过就不再跑）。
执行明细  每次执行都会落库。默认只看「当前账号 + 今天」，不会一上来就把
          全部记录翻出来（那样会卡）。表格每页 20 条，底部可翻页 / 跳页。
          列里单列一列「获得」，直接显示这一步拿到多少货币。
          可以按账号、时间范围、结果、关键词筛选，也能一键导出成 CSV
          （Excel 打开不乱码）。
设置      adb 路径（留空自动检测）、请求间隔（建议不低于 2 秒）。
          「开机自动启动」勾上后，登录 Windows 就会自动打开本程序，
          配合任务页的定时执行，可以做到开机后无人值守自动签到；
          取消勾选即关闭（写的是当前用户的启动项，不需要管理员权限）。
          下方「数据维护」显示当前记录条数和数据库占用，可一键清理 90 天前的
          执行记录（只删历史明细，不影响账号和签到状态）。
          再往下是「关于」区：一个「GitHub Releases」按钮，点一下自动查
          最新版本并直接开始下载安装包（接口不通时退回发布页）；
          下方小字显示当前版本号和发布页地址。


五、各社区任务完成情况
------------------------------------------------------------------------
【库街区】全部可用，每日 80 库洛币可拿满
    · 社区签到                     +30
    · 游戏签到（鸣潮 / 战双）        按账号绑定的默认角色
    · 浏览 3 篇帖子                 +20
    · 点赞 5 次                    +20
    · 分享 1 次帖子                 +10

【米游社】
    · 游戏每日签到                 可用（按账号已绑定的角色逐个签，含崩3 双角色）
    · 社区签到（打卡）              可用，+30 米游币
    · 任务进度 / 米游币余额查询       可用
    · 自动领取已完成任务奖励          可用
    · 点赞、分享                   接口调用会成功，但米游社只按 App 内的真实操作
                                  计任务进度，所以不会推进「完成5次点赞」「分享帖子」
                                  这两条任务条。功能保留，效果有限。
    · 浏览 / 评论 / 发帖            需要驱动 App 真实界面，当前版本未开放。

【Trae】PC 工具签到（不需要模拟器）
    · 每日签到领积分                可用
    添加方法：保持 Trae 客户端登录，账号页 →「登录账号」→ 平台选 Trae →
    「自动获取」→「立即获取登录凭证」，程序会自动从 Trae 进程里读取登录态。
    读不到时（客户端没开 / 没登录）切到「手动添加」，粘贴抓包工具里
    Authorization 请求头的值（Cloud-IDE-JWT 开头，整段粘贴即可）。
    导入时会顺带读取账号昵称，账号列表里显示的就是昵称而不是一串数字；
    签到成功的日志末尾会写 +N 积分（服务端没回数量时按当日签到额度补）。

【Qoder】PC 工具签到（不需要模拟器）
    · 每日领取 100 Credits          可用
    每天 10:00（UTC+8）刷新一轮，领取后 30 天有效。
    添加方法：账号页 →「登录账号」→ 平台选 Qoder →「自动获取」→「立即获取登录凭证」，
    程序会自动读取本机 Qoder 客户端的登录态（dt- 开头的设备令牌）。
    读不到时（没装客户端 / 没登录 / 版本改了加密格式）再切「手动添加」粘贴：
    抓包工具里 Authorization 请求头 Bearer 后面那段（带不带 Bearer 前缀都认）。

    国内版和国际版是两套独立服务，token 不通用：
      · 国内版客户端 → https://openapi.qoder.com.cn
      · 国际版客户端 → https://openapi.qoder.sh
    导入时会自动判断 token 属于哪个版本，不用你选。如果提示「token 已失效」，
    说明两个域名都不认这段 token —— 多半是抓的旧请求，重新登录客户端再抓一次。

【WorkBuddy】PC 工具签到（不需要模拟器）
    · 每日签到领积分                可用
    添加方法：保持 WorkBuddy 客户端登录，账号页 →「登录账号」→ 平台选
    WorkBuddy →「自动获取」→「立即获取登录凭证」，程序会自动从客户端
    进程里读取登录态并用接口验证（token 约 30 天有效，客户端重新登录后
    再获取一次即可更新）。
    客户端没开或读取失败时的备选：切「手动添加」，浏览器登录 www.workbuddy.cn，
    F12 → Network，点一次签到，请求右键「Copy as cURL」整段粘进 token 框。


六、常见问题
------------------------------------------------------------------------
Q：提示「没有已连接的模拟器」
A：模拟器没启动，或没开 ADB 调试。先在模拟器设置里打开 ADB，再点「登录账号」→
   「自动获取」重试。
   同时开了多个模拟器时，只保留一个在运行，避免连到错误的设备。

Q：提示「未找到 adb」
A：程序自带的 adb 在安装目录的 bin 文件夹里。若被安全软件隔离，请恢复该文件；
   也可以在「设置」里手动填写模拟器自带 adb.exe 的完整路径。

Q：提示未找到 token / 校验失败
A：在模拟器里打开对应 App 手动登录一次，保持 App 在前台，再重新提取。

Q：签到提示「今日已签到」
A：正常。说明今天签过了，服务端不会重复发放，不算失败。

Q：米游社提取凭证很慢
A：需要扫描 App 进程内存找 stoken，10～40 秒属正常。期间不要关闭模拟器或 App。

Q：昨天还能用，今天提示 token 失效
A：凭证会因重新登录、换设备、长时间未使用而失效。重新「登录账号」→「自动获取」一次即可。

Q：Windows 提示「已保护你的电脑」
A：安装包没有购买代码签名证书，属正常现象。点「更多信息」→「仍要运行」。

Q：杀毒软件报毒
A：程序会通过 adb 读取模拟器内的 App 数据，行为特征类似调试工具，可能被误报。
   本程序不联网上传任何数据，可将其加入信任列表。

Q：界面文字太小 / 高分屏模糊
A：程序已按系统缩放自适应。如仍不适，可在 显示设置 里调整缩放比例后重启程序。


七、数据位置与卸载
------------------------------------------------------------------------
账号凭证、执行记录、设置都保存在：

    C:\Users\<你的用户名>\.signrover\
        signrover.db     账号与执行记录数据库
        settings.json    程序设置

卸载方法：
    方式一  控制面板 →「程序和功能」→「社区签到助手」→ 卸载
    方式二  运行安装目录下的 uninstall.exe

程序安装目录（英文路径，便于脚本与安全软件识别）：
    D:\Games\SignRover\
        主程序  SignRover.exe
        工具    bin\adb.exe

默认装在 D:\Games\SignRover。安装向导第二步可以改成别的位置；
若这台机器没有 D 盘，程序会退回 C:\Users\<你的用户名>\AppData\Local\Programs\SignRover\。
以后覆盖安装会自动沿用上次装的位置，不会把已装在 D 盘的程序又装回 C 盘。

卸载不会删除上面的数据目录。如需彻底清除，手动删除 .signrover 文件夹即可。
重新安装后，原有账号仍然保留。


八、注意事项
------------------------------------------------------------------------
· 本工具仅供个人账号日常签到使用，请勿用于批量或商业用途。
· 使用自动化工具可能违反社区用户协议，存在账号风险，请自行评估后再使用。
· 请求间隔建议不低于 2 秒。频率过高容易触发风控，导致接口 403 或临时限制。
· 程序行为等同于你自己在 App 里点签到，不会修改任何游戏数据。
